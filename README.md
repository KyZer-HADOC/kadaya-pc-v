# KADAYA

2D dark ninja platformer (MonoGame / C#). You are The Grim Reaper.
Run left to right through each level, cross pits, dodge spikes, cut down ninja / samurai / archers,
defeat the boss at the end, then step through the Soul Gate. Die and you restart from the last
shrine of the SAME level (progress is saved).

## Run
1. Install the .NET 8 SDK: https://dotnet.microsoft.com/download
2. In this folder: `dotnet run`

## Build setup.exe
Push to GitHub -> Actions tab -> "Build KADAYA setup.exe" -> download artifact `KADAYA-setup`.

## Controls
A/D move | W/Space jump (x2) | Shift shadow step | J scythe combo | K soul kunai
Hold L Soul Rasengan | E Shadow Clone Jutsu | Q Death's Eclipse | Enter confirm | N new game | F11 fullscreen | Esc quit

## Levels
1. Blood Moon Forest - boss: Oni Warlord
2. Haunted Graveyard - boss: Wraith Lord
3. Burning Temple    - boss: Fire Shogun
